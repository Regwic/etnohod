# Этноход

Детское интерактивное путешествие: создание героя, карта регионов, история Башкортостана, мини-игры, книга открытий и кабинет учителя.

## Локальный запуск

Нужен Python 3:

```sh
python3 -m http.server 8130 --directory dist
```

Откройте http://localhost:8130. Сборка и установка зависимостей не требуются.

## Публикация на Vercel

Импортируйте этот репозиторий. Framework — Other, Output Directory — `dist`. Настройки также записаны в `vercel.json`.

## Данные

Это браузерный прототип: профили, прогресс и классы сохраняются локально, без серверной синхронизации и защищённой авторизации. Демо-код класса: `ETNO5`.

## Структура

- `dist/` — HTML, CSS, JavaScript и иллюстрации
- `ART_ASSETS.md` — описание визуальных ресурсов
- `VISIT_CONCEPT_STATUS.md` — состояние игровых функций

## ИИ-куница

Куница вызывает серверный маршрут `POST /api/marten` в Vercel. Для ИИ-ответов добавьте в настройки проекта две серверные переменные и переопубликуйте деплой.

- `CLOUDFLARE_ACCOUNT_ID` — идентификатор аккаунта Cloudflare.
- `CLOUDFLARE_AI_TOKEN` — токен с доступом к Workers AI для этого аккаунта.

Используется модель Llama 3.3 70B через Cloudflare Workers AI. На бесплатном тарифе запросы ограничены дневной квотой. Чтобы гарантированно избежать расхода сверх квоты, используйте аккаунт на плане Workers Free. [Тарифы и квоты](https://developers.cloudflare.com/workers-ai/platform/pricing/) · [Настройка REST API](https://developers.cloudflare.com/workers-ai/get-started/rest-api/)

Диалог хранится в текущей вкладке и не записывается в профиль. Провайдеру передаются вопрос, до трёх предыдущих пар реплик и контекст остановки. Имя героя и данные класса не отправляются. Если API недоступен, на остановках остаются подсказки из игры, а поиск по материалам работает на странице спутника.

Статический запуск через Python подходит для проверки интерфейса и локальных подсказок. Для проверки ИИ нужен деплой с настроенными переменными.

## Хакатон `test/hackathon`

`hackathon/` содержит отдельный кабинет учителя и мини-игру «В гостях у Данияра».
Один участник соответствует одному персональному приглашению. Действия проверяются
на сервере, прогресс и результаты сохраняются в D1. Таблица обновляется каждые
4 секунды и выгружается в CSV для переноса статистики.

- `/teacher` — вход учителя, приглашения и таблица.
- `/play#…` — игра по приглашению с продолжением с последнего ответа.
- `node --test hackathon/worker.test.mjs` — проверка API на SQLite.

Для отдельного тестового развёртывания нужны Worker с привязкой D1 `DB`,
миграция из `hackathon/migrations/` и серверный секрет `TEACHER_KEY_HASH`
(SHA-256 в hex от случайного ключа учителя в base64url). Локальная сборка
`node hackathon/build.mjs <каталог>` использует манифест Sites в корне.
